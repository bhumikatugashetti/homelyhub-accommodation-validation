\# HomelyHub – Accommodation Form Validation



\## Overview



This repository contains my contribution to the HomelyHub project, focused on improving the accommodation listing form through client-side validation.



\## My Contribution



I implemented client-side validation for the accommodation listing form to prevent incomplete or invalid accommodation details from being submitted.



\### Validations Implemented



\- Property name validation

\- Property type validation

\- Room type validation

\- Address validation

\- Minimum image upload validation

\- Description validation

\- Check-in and check-out validation

\- Guest count validation

\- Price validation

\- Numeric data preparation before API submission



\## Technologies



\- React.js

\- JavaScript

\- Redux

\- Client-side form validation

\- REST API integration



\## Purpose



The goal of this contribution is to improve the reliability of accommodation data submitted through the frontend and provide users with immediate feedback when required information is missing or invalid.



\## Project Context



HomelyHub is an AI-powered stay booking platform. This repository represents my specific contribution to the accommodation listing functionality rather than the complete HomelyHub application.
